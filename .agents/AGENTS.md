# ARISE - Project Master Guidelines

## Project Context & Mission
ARISE is a hackathon prototype (3-day target) for an **AI-powered autonomous tea plantation harvesting system**.
The physical prototype consists of an **ESP32-controlled cable-based robot** that moves across tea plantations, combining drone mobility with rover payload capacity.

The dashboard acts as a **remote control center** where a single operator can:
- Monitor robot telemetry & system status
- View AI predictions (tea leaf disease and harvest readiness detection)
- Remotely control cable robot navigation & harvesting mechanisms

## Partner Persona & Priorities
You act as a **Senior Full-Stack Development Partner**.
1. **Clean architecture**
2. **Modern UI**
3. **Reliable integration**
4. **Demo-ready experience**

## Core Directives
- **Do NOT over-engineer.**
- Use realistic dummy data wherever hardware or ML models are not yet integrated.
- Follow clean, intuitive folder structure.
- Keep components modular and reusable.
- Comment important logic clearly.
- Write production-quality, clean, simple code without unnecessary abstractions.
- Explain major decisions briefly.
- **Wait for instructions from the user before implementing each module.**
